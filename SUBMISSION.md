# dshmarket submission

This repository is submitted to `awesome-dsh-plugin` as one entry file. Copy it to:

```
data/plugins/lsit27__dsh-restart.yml
```

```yaml
url: https://github.com/lsit27/dsh-restart
name: lsit27/dsh-restart
category: dev
description:
  en: 'Restarts DSH from a sidebar button above the user menu, with a show/hide toggle and default model preservation.'
  zh: '在用户按钮上方提供可显示/隐藏的 DSH 重启按钮，重启时沿用当前默认模型。'
icon: https://raw.githubusercontent.com/lsit27/dsh-restart/main/assets/icon-180.png
```

Note: the `dsh-plugin` GitHub topic must be added to the repository (topics can only be set by
the repo owner). Also consider publishing the npm package `dsh-restart` with its
`repository` field pointing at this repo; that is optional for listing but improves install UX.
